Homeassistant Bridge is an independent, open-source bridge designed to integrate with:

- Home Assistant (https://www.home-assistant.io/)
- MeshMonitor (https://meshmonitor.org/)
- MQTT brokers such as Mosquitto or other compatible implementations
- Python libraries including:
  - paho-mqtt
  - websockets

This project connects to Home Assistant using its official WebSocket API and communicates with MeshMonitor using standard MQTT messaging. It does not bypass authentication, scrape services, rebroadcast proprietary feeds, or distribute shared credentials.
